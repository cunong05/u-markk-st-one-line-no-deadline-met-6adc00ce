# One Line, No Deadline Met

A make.fun entry for the competition [One Line, No Deadline Met](https://make.fun/c/u-markk-st-one-line-no-deadline-met-6adc00ce/).

The program writes one single-line joke giving an excuse for a missed
deadline to `/output/entry.txt` — that line and nothing else: no picture,
no link, no second line.

## Entry

> I didn't miss the deadline, I just extended it in my head and forgot to tell anyone.

## Run

```sh
python3 main.py
```

This creates `/output/entry.txt` containing exactly the entry above
(84 characters, one line, UTF-8).
